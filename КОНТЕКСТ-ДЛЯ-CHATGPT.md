# Каталог автодеталей Langyu

Это офлайн-витрина из 309 товаров продавца Guangzhou Langyu Auto Parts Co., Ltd. на 1688. Витрина помогает искать запчасти по модели автомобиля, коду кузова, названию и ID товара, смотреть варианты, характеристики и фотографии, оценивать стоимость в рублях с доставкой.

Перед изменениями прочитайте [общие инструкции для обоих участников](AGENTS.md). В них описано, как согласовывать параллельные задачи через GitHub и когда публиковать обновления.

## Что прикрепить к чату

1. Прикрепите этот файл и `products.js` из распакованной папки `Langyu-Catalog`. Для русских названий и словаря также приложите `ru.js` и `localize.js`.
2. Если вопрос о надписи на фото, приложите само изображение из папки `photos` или скриншот нужной карточки. Пути к файлам в `products.js` относятся к папке на вашем компьютере.
3. Цена для Авито считается по фиксированным ставкам в `avito.js`.

Пример запроса для ChatGPT: «Найди в каталоге крышки багажника для BMW E46 с четырьмя дверями. Приведи ID, варианты и цены. Отдельно укажи, какие сведения о совместимости привёл продавец и что нужно уточнить».

## Структура файлов

| Файл | Для чего нужен |
|---|---|
| `index.html` | Открывает витрину в браузере после распаковки. |
| `products.js` | Основные данные. Текст начинается с `window.products =`, дальше идёт JSON-массив карточек. Для анализа достаточно прочитать массив как данные. |
| `ru.js` | Ручной перевод 12 демонстрационных карточек и часть словаря характеристик. |
| `localize.js` | Русские подписи, словарь автодеталей и правила автоматического перевода для остальных карточек. |
| `pricing.js`, `avito.js` | Расчёт доставки, фиксированные курсы и описания для Авито. |
| `photos/` | Фото галереи, вариантов и описаний. Общие баннеры продавца исключены. |

## Что означают поля товара

- `id` — уникальный ID предложения 1688. По нему связывайте товар, варианты, фото и отзывы. `url` — ссылка на карточку продавца.
- `title`, `description`, `specs` — оригинальные заголовок, текст описания и характеристики. У многих товаров описание представлено изображениями. `photos` — галерея, `descriptionPhotos` — изображения из описания.
- `price`, `price_min`, `price_max` — цены в юанях. `moq` — минимальный заказ; `unit` — единица товара. `price_tiers` — цены по количеству. `skus` — варианты с названием, ценой и остатком, когда они указаны.
- `unit_weight_kg` — заявленный вес для отправки, кг. В `package_sizes` есть габариты в сантиметрах и вес в граммах (`weight_g`), иногда отдельно по вариантам. При расчёте сверяйте название варианта с `package_sizes[].sku`.
- `dispatch`, `ships_from`, `services` — сроки, откуда отправляют, гарантии и условия возврата. `shipping_fee` относится к условиям 1688 и хранится в юанях. Тариф в `avito.js`, используется для отдельной оценки доставки в рублях.
- `sold_count`, `sold_text` — опубликованные сведения о продажах. Период и округление могут различаться. `dropship.figures` — показатели продаж через партнёров; «до 100» означает диапазон. `returnRate` в этом блоке обозначает долю покупателей, оставивших товар у себя; количество фактических возвратов в выгрузке отсутствует.
- `review_score`, `review_count` — сводка из карточки. Значения одинаковы в исходной выгрузке у всех товаров, их независимая достоверность для каждого товара не подтверждена. В `reviews` есть две найденные записи для товара `681482058629`, одна помечена как шаблонная.

## Как помогать с каталогом

- В ответе приводите ID или ссылку на 1688, чтобы человек мог открыть исходную карточку.
- Сверяйте совместимость по заголовку, характеристикам и вариантам. Если заголовок говорит «A4, S4, RS4», а в вариантах указан только A4 B9, для S4 и RS4 следует запросить подтверждение продавца. Коды кузовов, рестайлинг, год, сторона установки и материал не угадывайте.
- Различайте углеволокно, сухой и мокрый карбон, полимерную смолу, АБС-пластик и рисунок под карбон. Автоматический перевод может опускать уточнения. Сверяйте их с китайским оригиналом и фотографиями.
- Для цены товара в рублях умножьте цену за штуку в юанях на 15 ₽/¥. Для доставки перемножьте длину, ширину и высоту упаковки в сантиметрах и разделите на 1 000 000. Затем умножьте объём в м³ на 300 $/м³ и 100 ₽/$. Если габариты требуют уточнения, итог с доставкой не рассчитывается. Итог в рублях — цена товара плюс доставка.
- Данные отражают выгрузку от 19 ноября 2026 года. Цены и остатки могут измениться. Если нужного значения нет, прямо укажите это.
