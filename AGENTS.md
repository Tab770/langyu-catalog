# Работа над каталогом Langyu через ChatGPT

Этот порядок действует для обоих участников проекта. GitHub — общий источник состояния задач и каталога. Техническое устройство витрины описано в [«Контексте для ChatGPT»](КОНТЕКСТ-ДЛЯ-CHATGPT.md).

## Начало задачи

1. Прочитай этот файл и контекст из актуальной `main`. Проверь [открытые pull requests](https://github.com/Tab770/langyu-catalog/pulls), включая черновики.
2. Работай в отдельной ветке от актуальной `main`. Когда появится первый содержательный коммит в задаче с несколькими правками, открой черновой PR. Укажи цель, затронутые файлы или функции, а для изменений товаров — их ID 1688, если известны. Дополняй описание при изменении объёма работы.
3. Если другой PR меняет тот же файл, проверь, пересекаются ли конкретные функции или ID. С разными объектами можно работать параллельно. При пересечении согласуй порядок с участниками через текущий чат и зафиксируй зависимость в PR. После объединения первой задачи обнови вторую ветку из `main` и проверь совместный результат.

## Проверка

- Объединяй в одном PR связанные изменения, например товар, его фотографии и перевод.
- Для карточек проверяй ID, исходные цены, варианты и пути к фото. Для витрины проверяй затронутые сценарии, например поиск, категории и открытие карточки. Для расчётов проверяй курс, правила доставки и отображаемые суммы.
- В PR укажи, что изменилось, что проверено и какие проверки остались недоступны. Когда задача готова, передай пользователю ссылку на PR.

## Публикация

1. Объединяй PR с `main` после явной команды «опубликуй» или равноценного указания от любого из двух участников. Пока такой команды нет, оставляй готовые изменения в PR.
2. Перед объединением снова проверь актуальную `main` и связанные PR. Если появились пересекающиеся изменения, обнови ветку и повтори затронутые проверки. Публикуйте задачи по очереди.
3. После объединения проверь запуск GitHub Pages для нового коммита, дождись результата и сообщи статус. Если витрина доступна для просмотра, проверь опубликованное изменение по [ссылке каталога](https://tab770.github.io/langyu-catalog/).
